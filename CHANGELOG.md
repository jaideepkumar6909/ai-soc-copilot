# Changelog

## Portfolio release — 2026-10-03

- Bundles the working SSH correlation engine, Streamlit interface, Claude adapter,
  three dashboard demos, and eight-scenario evaluator.
- Includes structured JSON output, local validation, and prompt `ssh-review-v2`.
- Documents the actual 7/8 live evaluation result and known qualitative failures.
- Adds setup, architecture, supported scope, troubleshooting, security guidance,
  contribution guidance, and publication materials.
- Adds exclusions for local data and credentials.

This packaging release does not fix model/rule disagreement or change the model's
semantics after the recorded evaluation. Those remain documented future work.
